# EEZ Studio project

The UI is designed in EEZ Studio (LVGL 8.4, native actions, no EEZ Flow) and the firmware uses
the code generated from it. The SquareLine Studio UI it was converted from is kept in
`squareline_prj/` for reference only.

## Contents

| | |
|---|---|
| `uaDash.eez-project` | **the design (edit this one)**, 800x480, 4 screens: `main_screen`, `bench_screen`, `settings_screen`, `engine_config_screen` |
| `uaDash_1024x600.eez-project` | generated by `tools/eez_build.py` for 1024x600 boards, do not edit |
| `actions.md` | the 54 native actions and the event handlers they call |
| `assets/fonts/x14y24pxHeadUpDaisy.ttf` | font source, see [OFL.txt](assets/fonts/OFL.txt) |

Generated code: `firmware/src/ui_eez/800x480/` and `firmware/src/ui_eez/1024x600/`,
included through `firmware/ui_eez.h` (also generated).

## Workflow

1. Edit `uaDash.eez-project` in EEZ Studio (800x480). Do not edit the 1024x600 project.
2. Build both variants (needs EEZ Studio installed and Python with Pillow):

   ```
   python tools/eez_build.py
   ```

   It builds the 800x480 project, generates the 1024x600 project (everything scaled by 1.25,
   fonts regenerated from the TTF, images resampled, centered horizontally), builds that one
   too, guards every generated `.c` file with the board define (Arduino IDE compiles all of
   `src/`) and writes `firmware/ui_eez.h`.
3. Build the firmware as usual (ESP-IDF or Arduino IDE).

| board | UI variant |
|---|---|
| Waveshare ESP32-S3-Touch-LCD-7B (1024x600) | 1024x600 |
| Waveshare ESP32-S3-Touch-LCD-5, other 800x480 boards | 800x480 |

### Firmware side

* Actions (`action_<name>(lv_event_t *e)`) are implemented in `firmware/actions.cpp`. A new
  action added in EEZ Studio needs a function there.
* Widgets are reached as `objects.<identifier>`. `firmware/ui_eez.h` also defines the old
  SquareLine names (`ui_rpmWarnVal` -> `objects.rpm_warn_val`) used by `updaters.cpp` and
  `events.cpp`.
* The main screen values are set in `updaters.cpp` (`dashboardInit()`, `fastUpdate()`,
  `midUpdate()`, `slowUpdate()`).
* Screen changes use EEZ `loadScreen()` (200ms fade).

## Main screen: FULLMONI-WIDE design

The main screen is the FULLMONI-WIDE "eez002" dashboard (800x256), imported by

```
python tools/eez_import_fullmoni.py <path to FULLMONI-WIDE/Firmware/eez/eez002/eez002.eez-project>
```

It replaces `main_screen` with the left gauges (water, IAT, oil temp, MAP, oil press,
battery), the tachometer (needle, arc, peak hold), RPM value, gear and AFR, inside the
container `dashboardBand` centered on the screen. Speed, clock, trip/odo, fuel gauge and the
lambda table are left out. Running it again overwrites changes made to the main screen.

## Conversion notes (SquareLine -> EEZ, `tools/squareline_to_eez.py`)

The initial project was created from the SquareLine export (`squareline_prj/export/`).
Running the converter again overwrites `uaDash.eez-project`.

* Positions, sizes, alignment, styles (colors, opacity, radius, gradients, borders, outlines), flags,
  bar ranges and texts are taken over 1:1. Object names are kept without the `ui_` prefix
  (`ui_rpmVal0` -> `rpmVal0`).
* Fonts are replaced by the HeadUpDaisy pixel font. It is a 14x24 dot font: sizes that are
  multiples of 24px keep every dot on whole pixels.

  | SquareLine font | use | EEZ font |
  |---|---|---|
  | FontLabel 16px, FontIndicator 18px, FontRPM 26px, Montserrat 26px | labels, values | `hud_24` |
  | FontIndicatorLabel 10px | bar scale ticks | `hud_12` (half dot) |
  | FontSpeed 160px | speed | `hud_168` (digits only) |

* The SuperBrigade based fonts had capital letters only, those texts are upper-cased.
* The SquareLine move animations are not used (see docs/adr/0001-build-with-esp-idf.md).
